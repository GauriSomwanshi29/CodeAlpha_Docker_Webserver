05 DEPLOYMENT WORKFLOW

From source to localhost

Five deliberate steps. Every one is reproducible — the whole deployment can be torn down and rebuilt from scratch in under a minute.

01

Create HTML website

Design and build the static site — markup, styles, scripts and 3D visuals, all self-contained.

02

Write Dockerfile

FROM nginx:latest, copy the site into the Nginx docroot, EXPOSE 80.

03

Build Docker Image

docker build -t codealpha-webserver . — layers cached, build is fast and repeatable.

04

Run Docker Container

docker run -d -p 8080:80 — the container starts detached and maps ports.

05

Access through localhost

Open http://localhost:8080 — the containerized Nginx server delivers the site to the browser.

06 ABOUT PROJECT

Why containerize a web server?

The objective of NEXUS is simple and precise: take a website and the web server that delivers it, wrap both inside a Docker container, and run that container as a self-sufficient unit on localhost:8080.

Instead of installing and configuring Nginx directly on the host machine, the Dockerfile packages the official Nginx image together with the site's static assets. The result is a deployment that is isolated from the host, reproducible on any machine with Docker, and trivially portable — the same image that runs on a laptop under WSL2 runs unchanged on any cloud server.

This project demonstrates the core DevOps workflow — containerization, image building, port mapping and container management — applied to a real, fully hand-built web experience: the one you're looking at right now, served from inside the container.
