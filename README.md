## 🌌 About The Project

**NEXUS** is a modern, futuristic web infrastructure project that demonstrates Docker-based containerization and Nginx web server deployment.

It combines an interactive website with practical DevOps implementation, including container lifecycle management, resource monitoring, and automated health checks.

🌐 **Explore the Website:** [DOCKERNOVA | Docker Infrastructure](https://dockernove.netlify.app/)

*Note: The localhost link works only when the Docker container is running on your machine.*

## ✨ Key Features

* 🎨 Futuristic UI with glassmorphism and neon effects.
* 🌐 Interactive 3D visuals and smooth animations.
* 🐳 Docker-based website containerization.
* ⚡ Nginx web server deployment.
* 🔄 Container lifecycle management.

## ⚙️ Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/GauriSomwanshi29/CodeAlpha_Docker_Webserver.git
```

**2. Navigate to the project**

```bash
cd Code_Alpha_Docker_Webserver
```

**3. Build Docker image**

```bash
docker build -t codealpha-webserver .
```

**4. Run the container**

```bash
docker run -d -p 8080:80 --name my-webserver codealpha-webserver
```

**5. Open in browser**

```text
http://localhost:8080
```

## 🐳 Useful Docker Commands

| Command                       | Purpose                 |
| ----------------------------- | ----------------------- |
| `docker ps`                   | View running containers |
| `docker ps -a`                | View all containers     |
| `docker stop my-webserver`    | Stop container          |
| `docker start my-webserver`   | Start container         |
| `docker logs my-webserver`    | View logs               |
| `docker stats my-webserver`   | Monitor resources       |
| `docker inspect my-webserver` | Inspect container       |
